# Отчёт по кейсу Support Copilot

## Статус

**Полное соответствие кейсу пока не подтверждено.** Приложены правила, черновая таксономия и 1000 обращений; отдельная реальная база знаний, метки категорий/приоритетов и человеческие оценки не предоставлены. Решение — локальный эвристический baseline с извлекающим поиском, а не обученная модель или LLM. Отдельные обращения, ответы и производные выборки в этот отчёт не включены.

## Валидация 30 октября 2026 года

Проверена предоставленная HTML-обёртка с 1000 отдельными JSON-строками; JSON читался напрямую, без HTML DOM. Загружено 266 нумерованных пунктов правил и таксономия `draft-2026-10-27`. Набор использовался также для анализа ограничений и доработки, поэтому это не независимый от разработки тест качества.

| Показатель | Результат | Ограничение |
|---|---:|---|
| Обработано обращений | 1000 | Не подтверждает правильность ответов |
| Разметка категории / accuracy | 0 / `null` | Меток нет |
| Разметка приоритета / macro-F1 | 0 / `null` | Меток нет |
| `needs_human: true` | 1000 / 1000 | Не является оценкой качества эскалации |
| Черновики с номером правила | 130 / 1000, 13,0% | Наличие номера не доказывает релевантность |
| Правило требуется по предсказанной категории | 849 | Это не экспертная разметка |
| Из них с цитатой / без цитаты | 130 / 719 | Без цитаты черновик помечен неполным и требующим человека |
| Загружено статей базы знаний | 0 | Требуемый кейсом источник отсутствует |
| Оценка черновиков и релевантности цитат людьми | 0 / `null` | Проверка не проводилась |
| Оценки языков носителями KK/UZ | 0 / `null` | Качество не подтверждено |

Структурная проверка на этой выборке не обнаружила ссылок на несуществующий номер, раздел или не включённый в черновик отрывок. **Это проверка происхождения текста, а не доказательство смысловой релевантности**: каждый найденный пункт всё равно должен проверить человек. Все обращения без обязательной цитаты на этой выборке помечены как требующие человека и имеют предупреждение о неполном черновике. Ни одна проверка не доказывает, что сервис обнаружил все опасные случаи.

Подготовка детерминированных приватных выборок для 100 обращений проверена, но люди их ещё не размечали. Поэтому средний балл черновиков, точность категорий и показатели проверки цитат не выдумываются. Рекомендованы раздельная слепая разметка категорий/приоритетов и оценка ответа администраторами, а для KK/UZ — проверка носителями языка; инструкция и поля находятся в [README.md](README.md).

Дополнительно прошли 92 автоматических теста на синтетических данных, сквозная проверка очереди и админки в браузере и проверки axe на двух страницах, трёх ширинах и трёх языках интерфейса. Эти проверки не заменяют экспертную оценку реальных обращений.

## Время и стоимость

Локальная проверка проведена на Linux x86_64, Python 3.11.2, процессор Intel Xeon 2,60 ГГц, среда сообщила о двух логических CPU. Один клиент последовательно отправил 1000 запросов на временный loopback-сервер с изолированной SQLite-очередью:

- 1000 ответов HTTP 200, 1000 результатов прошли структурную проверку, 1000 подтверждений `queued`; ошибок передачи требующих человека обращений — 0.
- HTTP p50 **3,623 мс**, p95 **5,234 мс**, p99 **7,734 мс**, максимум **11,272 мс**. Это один локальный последовательный замер без браузера и внешней сети, **не нагрузочный production-тест и не подтверждение SLA**.
- p95 вызова локального конвейера в отдельном запуске оценки — **1,363 мс**, без HTTP.
- Стоимость вызовов внешних LLM API — **0 USD за тикет**, поскольку они не используются. Полная стоимость вычислений, хранения и эксплуатации **не измерена** и не равна автоматически нулю.

Воспроизведение при наличии приватных файлов:

```bash
make evaluate IN=data/tickets_valid-2.HTML
make benchmark IN=data/tickets_valid-2.HTML REQUESTS=1000 WORKERS=1
```

Значения времени зависят от машины, числа клиентов, состояния диска и очереди; для практической оценки нужны нагрузочные испытания на целевой инфраструктуре.

## Оставшиеся требования до сдачи

1. Получить и проверить реальную базу знаний и окончательную таксономию. Без базы знаний требуемый поиск по ней отсутствует; загрузка синтетического примера не заменяет источник.
2. Получить независимую разметку категорий и приоритетов, измерить accuracy/F1 и полноту распознавания платежей, апелляций и компрометации аккаунта, включая смешанные языки.
3. Провести ручную оценку минимум 100 черновиков, проверить каждую цитату на смысловую релевантность, отсутствие обещаний и утверждений о непросмотренных скриншотах. Отдельно оценить RU/KK/UZ с носителями и указать размер каждой языковой подвыборки.
4. Проверить p95 на целевой нагрузке и рассчитать полную стоимость инфраструктуры. Не считать локальный замер и нулевую стоимость API доказательством production-показателей.
5. Учитывать ограничения: дедупликация хранится только в памяти одного процесса и зависит от порядка обращений; операторская очередь привязана к вкладке; правки администратора не обучают модель автоматически; отправки игроку, внешних уведомлений и интеграции с игрой нет. Соблюдать правила доступа и удаления всех данных и копий организаторов.
